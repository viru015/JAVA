# Quiz Game 🎮

A simple console-based Quiz Game developed using Java.

## About

This project is a basic interactive quiz application where users answer multiple-choice questions and receive a score based on their correct answers.

## Features

- Multiple-choice questions
- User input handling
- Answer checking
- Score calculation
- Interactive console interface

## Technologies Used

- Java

## How to Run

1. Clone this repository.
2. Open the project in a Java IDE such as IntelliJ IDEA.
3. Navigate to the `src` folder.
4. Run the main Java file.

## Purpose

This project was created to practice and improve my understanding of core Java programming concepts such as conditional statements, loops, user input, and basic program logic.
