# Dice Roller 🎲

A simple Dice Roller program developed using Java.

## About

This program simulates rolling a dice by generating a random number between 1 and 6 each time the user rolls.

## Features

- Generates random dice values
- Simulates a real dice roll
- Simple and easy-to-use program

## Technologies Used

- Java

## Purpose

This project was created to practice Java programming concepts such as random number generation and basic program logic.
