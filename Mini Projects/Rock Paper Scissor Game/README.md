# 🪨 Rock Paper Scissors ✂️

A simple Rock Paper Scissors game made using **Java**.

## 🎮 Features

- 👤 Player vs Player
- 🤖 Player vs Bot
- 🎲 Random choices for the bot
- 🏆 Displays the winner

## 🛠️ Technologies

- Java
- `Random` class
- Basic Java concepts

## 📚 What I Learned

This project helped me practice **Java basics, user input, conditional statements, loops, and random number generation**.
